# 📚 BukuKita / QR Book Scanner App (WIP)

> Aplikasi seluler berbasis Flutter untuk manajemen daftar buku dan pemindaian QR Code interaktif yang menampilkan informasi detail buku, harga, dan ketersediaan secara instan.

---

## 🚀 Status Project: Early Development (Phase 1)
Project ini sedang dalam tahap perancangan awal dan fondasi arsitektur. Beberapa fitur dasar sedang dibangun secara bertahap.

---

## 📱 Tentang Project
**BukuKita** dikembangkan untuk memudahkan pengguna dalam mengelola katalog buku sekaligus memberikan pengalaman pencarian informasi buku yang cepat melalui pemindaian *QR Code*. Cukup arahkan kamera ke kode QR pada buku, dan detail lengkap seperti harga, deskripsi, serta status stok akan langsung muncul di layar.

---

## ✨ Fitur Utama (Planned & In-Progress)

*   📸 **QR Code Scanner Integration:** Memindai kode QR unik pada setiap buku untuk melihat informasi instan.
*   💰 **Instant Price & Detail Display:** Menampilkan informasi harga, penulis, penerbit, dan sinopsis setelah pemindaian berhasil.
*   📖 **Book List Management:** Menampilkan daftar katalog buku yang bersih dan mudah dinavigasi.
*   🔍 **Search & Filter:** Memudahkan pencarian buku berdasarkan judul, kategori, atau penulis.
